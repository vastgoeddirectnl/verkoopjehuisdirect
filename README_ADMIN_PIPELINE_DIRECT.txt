Admin patch: pipeline en voorstelstatussen

Deze patch mag direct op main worden toegepast. De publieke website-inhoud wordt niet aangepast door deze patch.

Aangepast:
- Nieuwe pipeline-statussen voor leads
- Voorstel genereren zet lead op “Voorstel opgesteld” in plaats van “Voorstel verzonden”
- Voorstel mailen blijft status “Voorstel verzonden” gebruiken
- Quick pipeline-knoppen in het admin dashboard
- Dashboardblok met pipeline-overzicht
- Archief herkent ook “Afgewezen / vervallen”
- Automatisering en opvolgdatums begrijpen de nieuwe statussen
- Nieuwe aanvragen krijgen voortaan status “Nieuwe aanvraag”

Geen Neon/database-migratie nodig. Bestaande oude statussen blijven ondersteund.
